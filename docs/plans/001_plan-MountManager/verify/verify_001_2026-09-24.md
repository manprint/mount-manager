- Status: FIXED (2026-10-18, see verify/index.md for evidence)

- Category: untested
- Where: `internal/recovery/recovery_test.go:277` `TestRecoverContextCanceled`; plan 2.1 test oracle ("ctx cancellato → ctx.Err(), nessun down"); I-8.
